# Resoconto del lavoro con l'AI — Segnale

Data: 24 novembre 2026

- Ho utilizzato ChatGPT per analizzare la consegna,
  suddividerla in piccoli passaggi e comprendere
  il funzionamento di JSON, JavaScript e API.

- Ho fornito i file originali del sito e ho chiesto
  di essere guidato una modifica alla volta, senza
  delegare la realizzazione completa del progetto.

- Ho completato personalmente i due file JSON e
  creato il documento SCHEMA.md con il diagramma
  delle relazioni in Mermaid, seguendo le indicazioni
  ricevute.

- Ho utilizzato e integrato il codice JavaScript
  suggerito per generare dinamicamente le schede
  degli eventi, collegare le sedi, gestire gli errori
  e recuperare i dati meteorologici da Open-Meteo.
  Ho mantenuto lo stile grafico del sito originale.

- Durante il lavoro ho riscontrato alcuni problemi:
  uno spazio nel nome della cartella dati impediva
  il caricamento dei JSON, un tag HTML era in eccesso
  e la sezione meteo era inizialmente posizionata
  fuori dal contenitore principale. Ho individuato
  e corretto questi problemi con il supporto dell'AI.

- Ho verificato progressivamente le modifiche
  attraverso l'anteprima locale e la console di
  Google Chrome. Ho eseguito tutti e cinque i test
  richiesti dalla consegna, ripristinando i file
  originali dopo ogni prova.

- Ho controllato la visualizzazione responsive
  del sito a 375, 768 e 1280 pixel.

- Infine, ho aggiornato la repository GitHub
  esistente e verificato il corretto funzionamento
  del sito pubblicato su GitHub Pages.

L'AI è stata utilizzata come supporto didattico,
per ricevere spiegazioni, suggerimenti di codice
e assistenza nella risoluzione dei problemi.
Le modifiche e le verifiche sono state effettuate
personalmente.
